总体观点

jQuery是Web前端开发历史上划时代的里程碑工具。在那个各家浏览器标准割裂、IE与W3C标准水火不容的暗黑年代，它以一条‘write less, do more’的哲学统御了全球前端工程。

全书的核心灵魂在于链式调用（Chaining）、强大的CSS扩展选择器引擎（Sizzle），以及对跨浏览器DOM操作、事件系统与Ajax异步请求的无缝抹平。

通过从选择器基础、动画机制、表单增强到手写独立可扩展插件的进阶路径，读者不仅能掌握jQuery利刃本身，更能彻底理解现代前端框架底层操作DOM的来龙去脉。

核心观点

  1. 1. 强大的CSS选择器让DOM节点抓取变得轻而易举

    利用Sizzle引擎，一行$('div.content > ul li:first-child')即可横扫所有浏览器兼容性差异，秒杀繁琐的原生节点遍历。

    原生JS需要写十多行document.getElementsByTagName结合for循环筛选类名，jQuery只需一行$('.box p:odd')精准命中奇数段落。

  2. 2. 链式调用（Chaining）让代码逻辑如同流畅的流水线

    每个DOM操作方法默认返回当前jQuery包装对象本身，允许开发者将过滤、样式修改、事件绑定一气呵成连写下去。

    $('#menu').find('li').addClass('active').siblings().removeClass('active')，无需重复声明临时变量，三步操作一行流搞定。

  3. 3. 全方位抹平浏览器在事件模型上的深坑差异

    统一了W3C标准的addEventListener与旧版IE的attachEvent，自动标准化事件对象event，轻松搞定阻止默认行为与事件冒泡。

    原生代码需写if (e.preventDefault) e.preventDefault(); else e.returnValue = false;，jQuery只需直接return false或e.preventDefault()。

  4. 4. 事件委托（Event Delegation）轻松承载海量动态元素

    利用事件冒泡原理，将成百上千个子元素的监听器统一绑定在父容器上，即使后续动态异步追加新节点也能自动生效，性能飙升。

    表格列表使用$('#list').on('click', 'button.del', fn)，新加载出来的100行数据无需重新逐一绑定事件，点击即刻响应删除。

  5. 5. 一站式Ajax封装将异步网络请求变成极简体验

    彻底消灭手动实例化XMLHttpRequest与繁琐设置onreadystatechange的痛苦，提供$.get, $.post, $.ajax等直观API与全局拦截器。

    只需一行$.getJSON('/api/users', data, callback)，即可自动完成参数URL序列化、异步拉取与JSON自动解析全流程。

  6. 6. 规范的插件扩展机制构筑了全球最繁荣的开源生态

    通过向$.fn（即jQuery.prototype）扩展自定义方法，开发者能将轮播图、弹窗、下拉联动等组件标准化封装，实现全团队复用。

    编写$.fn.myTab插件，外部调用者只需一行$('#tabs').myTab({ autoPlay: true })，即可让任何HTML片段原地变成可交互选项卡。

全书结构

  1. 第1章 认识jQuery

    回顾前端刀耕火种时期的浏览器兼容噩梦，介绍jQuery诞生背景、优势、以及DOM对象与jQuery对象的转换互通准则。

    演示如何用$(domObj)将原生DOM转换为jQuery包装集，以及用$obj[0]反向取出原生DOM，澄清初学者的核心混淆点。

  2. 第2章 jQuery选择器

    巨细靡遗拆解基本选择器、层次选择器、基本过滤选择器、内容/可见性/属性/子元素及表单过滤选择器的Sizzle语法与性能。

    用一行$('input[name="gender"]:checked')精准定位当前处于勾选状态的单选按钮，展示属性与状态过滤器的强大组合拳。

  3. 第3章 jQuery中的DOM操作

    详解内部插入、外部插入、包裹、复制（clone）、替换、删除（remove/empty）以及属性/类名/HTML/CSS样式操作API。

    动态创建DOM节点$('<li>新项目</li>')并使用appendTo('#list')插入，结合clone(true)连同绑定的点击事件一并深度克隆。

  4. 第4章 jQuery中的事件和动画

    剖析$(document).ready与window.onload的区别、事件绑定/委托/解绑、合成事件，以及show/hide、slide、fade与自定义animate动效。

    使用hover合成事件两行实现鼠标悬浮菜单下拉与移开收起，利用animate({ left: '+=100px', opacity: 0.5 }, 500)实现平滑位移动画。

  5. 第5章 jQuery对表单、表格的操作及更多应用

    聚焦企业级开发高频场景：单选/复选框全选反选联动、文本框焦点高亮、表格隔行变色与高亮、多级级联下拉框过滤实战。

    实现全选复选框功能：监听顶层checkbox的change事件，一行$('tbody :checkbox').prop('checked', this.checked)实现批量联动。

  6. 第6章 jQuery与Ajax的应用

    拆解load、$.get、$.post、$.getScript、$.getJSON及底层$.ajax配置，传授全局Ajax事件（ajaxStart/ajaxStop）加载状态控制。

    利用$(document).ajaxStart($('#loading').show())与ajaxStop($('#loading').hide())，全站无需侵入业务即可自动展示请求加载菊花圈。

  7. 第7章 jQuery插件的使用和写法

    传授两类标准插件开发模式：封装对象方法的$.fn扩展与封装全局函数的$.extend扩展，规范命名空间与链式返回标准。

    手写一个高复用的表单验证插件$.fn.validateForm，支持链式调用并允许用户通过传入JSON配置项覆盖默认校验规则。

  8. 第8章 用jQuery打造个性网站

    综合全书全部技术栈，从零实战一个包含顶部品牌轮播图、左侧分类悬浮折叠、中间商品即时放大镜与购物车结算的完整商业网站。

    手把手带着读者实现类似电商详情页的图片局部放大镜特效：实时计算鼠标在小图上的相对坐标，动态等比变换大图的显示区域。
