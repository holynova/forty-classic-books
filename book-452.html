《断头螺丝》

作者： 何荣
出版社： 四川文艺出版社
出版年： 2021-12
豆瓣读书条目 →
8.5
★★★★☆
豆瓣评分 · 1,220 人评价
何荣扎根南方制造业车间十余载淬炼而成的现实主义小说集，聚焦五金模具与机床轰鸣间的流水线工人，以刀刻般的文字记录断指、锈蚀、尊严与异乡漂泊的生命实录。

总体观点

全球制造业繁荣与现代化奇迹的基石，是由数以亿计隐没在轰鸣车间里的底层工人用青春、骨血与机油味托举起来的，文学必须直面流水线旁真实的肉体创伤与生存重压。

工业机械的严密节奏与高速运转对工人体力与心智具有高度异化性，但在冰冷铁器与塑料熔浆之间，普通人依然倔强地维系着家庭责任、兄弟情义与对尊严的捍卫。

何荣以技术工人亲历者的精准视角，打破了知识分子居高临下的廉价同情与刻板想象，呈现出中国工业化进程中极其罕见、带有机械冷冽触感与泥土血腥气的原生态车间史诗。

核心观点

  1. 1. 工业节拍与肉身损耗：繁荣背后的沉重代价

    冲压机以一秒两次的频率砸下，那一声声闷响既是钞票落袋的节拍，也是随时可能吞噬食指的深渊，肉身的疲劳无法抵抗机械节奏。

    车间新进学徒因为连续加班十四小时在换料时迟疑半秒，右手食指第一节瞬间被冲床削去。

  2. 2. 微米级尊严：老派工匠在废铁堆中的自豪

    底层劳动者不仅具有苦难属性，更拥有高度专业的技术智慧与对抗工具异化的工艺自尊，这是他们最后的精神堡垒。

    老飞模师傅用砂纸打磨淬火钢件的手感，比最精密的千分尺还要毒辣，在数控机床面前依然保有一席之地。

  3. 3. 断头螺丝隐喻：极限施压下的隐性断裂

    一颗螺丝拧得太紧会在内部应力下突然断裂，深埋在零件深处取不出来，就像在城市流水线上耗尽心力被掏空的打工者。

    交货前夕紧固高压模具时关键螺丝突然断头，全厂技术骨干耗费整夜抢修，映射出人与零件在极限拉扯中的同构命运。

  4. 4. 黑白倒班的生理撕裂：被时钟剥夺的故乡记忆

    通宵两班倒切断了工人的昼夜生物节律，白天拉上遮光布睡不踏实，夜晚在刺鼻脱模剂中麻木穿梭，成为城市与故乡之间的局外人。

    打工青年在夜班休息十分钟的走廊拐角，捧着一盒热豆浆塞给相邻工位女孩，成为暗夜中唯一的温存慰藉。

  5. 5. 工伤理赔的尊严抗辩：拒绝被明码标价的肉身

    直面车间频繁发生的工伤事故，探讨伤残补偿谈判背后的法理、人情与个体尊严抉择，展现普通打工者的倔强脊梁。

    失去两根指头的年轻冲压工拒绝厂方私了的几万块现金，执着奔走要求出具正式工伤责任认定书与劳动保障。

全书结构

  1. 第一辑 车间声响：断头螺丝

    以同名核心篇目切入，讲述模具车间关键螺丝在交货前夕滑丝拧断引发的信任危机与惊心动魄的抢修过程。

    老工匠耗费整夜用反向螺纹丝锥与煤油小心翼翼旋出断丝，保住了全厂的订单也保住了徒弟的工钱。

  2. 第二辑 模具人生：飞模师傅

    刻画拥有二十年经验的模具老师傅在数控机床与老式手艺更替中的挣扎，展现老派工人的自尊与苍凉。

    老师傅面对年轻大学生的三维数控图纸，仅凭涂抹红丹粉压合研磨便指出两处微米级合模间隙缺陷。

  3. 第三辑 异乡流水：夜班与白班的交接处

    描写通宵两班倒流水线上的青年男女，在机油味与日光灯管闪烁中滋生出的短暂爱情与现实幻灭。

    青年工人在夜班休息的十分钟里，在车间走廊拐角把一盒热豆浆塞给相邻工位女孩的青涩温情。

  4. 第四辑 伤痕与尊严：冲压机的轰鸣

    直面冲压与注塑车间频繁发生的工伤事故，探讨伤残补偿谈判背后的法理、人情与个体尊严抉择。

    失去两根指头的年轻冲压工拒绝厂方私了的几万块钱，执着奔走要求出具正式工伤责任认定书。

  5. 第五辑 锈蚀岁月：回不去的故乡工棚

    展现打工二代与返乡老农工在城市城中村与凋敝故乡之间的心理撕裂，描摹精神流亡者的群体画像。

    在珠三角打工半生的老汉带着腰椎病回到湘西老家，却发现自己早已听不懂孙辈的方言与游戏语言。

  6. 后记：在机械节奏中寻找人性的微光

    作者回顾自己在车间与文字之间往返穿梭的创作历程，阐明为沉默大多数立传的文学初心。

    作者记述在噪音震耳欲聋的车间角落，利用废弃瓦楞纸箱背面用油性笔写下工友群像草稿的夜晚。
