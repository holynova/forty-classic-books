《编码的奥秘》

作者： [美] 查尔斯·佩佐尔德 (Charles Petzold)
出版社： 机械工业出版社
出版年：

豆瓣评分 · 16,500 人评价
计算机科学底层原理封神之作，从两个手电筒发报、电磁铁继电器一路手搭出算术逻辑单元与图灵完备CPU。

总体观点

计算机绝非神秘不可知的外星高科技黑盒，其最底层运转的所有复杂魔法，本质上都建立在极其质朴简单的物理与逻辑常识之上。从手电筒光线的明灭、莫尔斯电码的短长嘀嗒，到布尔代数的真假判断，人类利用‘开关状态’编码信息的智慧贯穿始终。

手把手演示如何用最原始的物理五金零件搭建计算机器。从干电池、导线与电磁铁组合成的‘继电器’（Relay），推导出与门（AND）、或门（OR）、非门（NOT），再将逻辑门拼接成半加器、全加器、触发器锁存器，层层递进堆叠出ALU运算器与RAM内存芯片。

打通从硬件电路到软件代码的全部底层通道。通过设计一套精巧的‘微指令集架构’与纸带控制总线，佩佐尔德向读者清晰展示了现代操作系统、汇编语言与图形显示器是如何一步步从硅片电信号的振荡中呼吸出来的，展现计算机工程学无与伦比的理性构造美。

核心观点

  1. 1. 莫尔斯电码与二元编码本质

    两个孩子隔着窗户用手电筒光芒传递秘密信息，点（短亮）与划（长亮）奠定了现代二进制数字世界的哲学基石：只要有两种截然不同的物理状态，就能编码人类语言文明的一切信息。

    通过分析英文字母使用频率，莫尔斯将最常用的E编码为单一短点‘·’，将罕见的Q编码为‘--·-’，生动预演了现代信息论香农熵压缩的底层直觉。

  2. 2. 继电器：从开关到逻辑门的飞跃

    继电器本质上是一个受电磁铁控制的机械弹性金属触点开关。当输入线有电流通过时，磁铁吸合触点闭合下游电路；通过交叉反向连接，便能用纯电信号实现‘取反’（NOT），消除了人手物理拨动开关的局限。

    两个继电器串联构成与门（全通才通），并联构成或门（一通即通），电流在金属触点间的流动直接完成了亚里士多德形式逻辑的物理实体化运算。

  3. 3. 加法器：电路如何学会算术

    二进制加法遵循纯粹的逻辑表：1+0=1（异或门负责和），1+1=0进位1（与门负责进位）。将一个半加器与一个全加器级联并排，八组这样的逻辑门串接在一起，就能完成任意两个8位二进制数的加法。

    通过引入‘反码与补码’概念，加法器甚至连减法运算都能无痛搞定，因为A-B在底层电路中被等价变换为A加上B的补码加法，省去了专门制作减法硬件的成本。

  4. 4. 触发器：电流如何记住过去

    普通的逻辑门没有记忆，输入一撤输出瞬间归零。但如果将两个或非门的输出交叉反馈回对方的输入端，就会形成一个自锁回路（RS触发器），能够在断开控制信号后永久维持上一刻的0或1状态，诞生了RAM内存。

    电平触发的D型触发器在时钟脉冲上升沿的一瞬间‘抓拍’输入端数据并锁存，八个触发器并联在一起，构成了计算机历史上第一个能够存储1个字节的寄存器。

  5. 5. 中央处理器CPU的自循环心跳

    将算术逻辑单元（ALU）、指令译码器、程序计数器（PC）和总线串联在一起，配以一个振荡器石英钟。在节拍器的每一次滴答声中，CPU自动执行‘取指-译码-执行-写回’的四部曲舞蹈，成为拥有无限计算潜能的图灵机。

    书中手绘一张涵盖全部连线的简化CPU全局架构大蓝图，读者顺着数据线信号高低电平逐个晶体管追踪，亲眼目睹一条`ADD`机器码指令如何让内存中的数字自动累加。

全书结构

  1. 第一部分 编码与电的相遇（第1-8章）

    从手电筒莫尔斯电码、布莱叶盲文、十进制与二进制转换讲起，引入干电池、手电灯泡与接地回路的物理电学常识。

    手绘展示用门铃电磁铁敲击金属弹片的物理连接图，演示电报机如何利用极细的铜线在数千英里外即时复现敲击声响。

  2. 第二部分 逻辑的五金机件（第9-16章）

    用电磁继电器实现布尔逻辑代数，组装与门、或门、反相器，逐步搭出半加器、全加器、八位加法器与减法求补器。

    详细演示用四个继电器交叉环绕搭建RS锁存器的完整接线图，解释‘竞争冒险’（Race Condition）与时钟同步信号的必要性。

  3. 第三部分 计算机成型：自控机器（第17-21章）

    引入程序计数器PC、只读存储器ROM与随机存储器RAM，设计指令集总线控制矩阵，让电路在时钟驱动下自动读取执行指令。

    设计一条‘条件跳转指令’（Jump if Zero），演示加法结果为零时ALU的Zero标志位如何强行重写PC计数器寄存器地址实现程序循环分支。

  4. 第四部分 飞入现实：微处理器与现代系统（第22-25章）

    从继电器平滑过渡到半导体真空管、晶体管与集成电路，解析Intel 8080微处理器、键盘扫描码、字符发生器ROM与图形界面。

    解构阴极射线管显示器（CRT）电子枪如何按扫描线逐行轰击荧光粉，以及显存中的字节如何通过移位寄存器逐个像素点亮屏幕。
