Web前端工业化时期的封神奠基之作，系统奠定基于语义化HTML、盒模型与CSS高级布局的现代网页重构科学标准。

总体观点

《精通CSS》是推动全球Web从野蛮的‘表格布局（Table-based Layout）与切图拼贴’走向基于语义化标记与层叠样式表（CSS）的‘现代Web标准运动’的里程碑灯塔。巴德极具前瞻性地指出：Web开发的灵魂在于‘结构（HTML）、表现（CSS）与行为（JavaScript）’的三层彻底解耦。抛弃冗余嵌套的table标签，使用具备语义内涵的div、ul、p标签，不仅能让网页加载速度提升数倍，更为搜索引擎爬虫与视障屏幕阅读器扫清了无障碍访问障碍。

CSS的核心机制并非简单的色彩字体声明，而是一套基于视口几何学与渲染流的高精度物理布局系统。盒模型（Box Model：内容、内边距padding、边框border、外边距margin）是所有视觉元素定位的原子砖块；层叠（Cascade）与继承（Inheritance）则通过特异度权重算法（Specificity）优雅消解样式冲突；而浮动（Float）与绝对定位（Position）构成了弹性多栏响应式布局的底层支柱。

掌握CSS的最高境界在于理解浏览器的‘Bug与排版上下文（BFC）’。在IE6/7横行的旧时代，‘IE双倍外边距Bug’、‘HasLayout隐藏私有属性’与‘外边距折叠（Margin Collapsing）’曾是无数前端开发者的噩梦。巴德以庖丁解牛般的深厚功力，系统阐释了闭合浮动（Clearfix）、优雅降级（Graceful Degradation）与渐进增强（Progressive Enhancement）工程思想，树立了专业前端工程师的技术尊严。

核心观点

  1. 1. 选择器特异度（Specificity）的权重算盘

    当多个CSS规则作用于同一个元素时，浏览器通过四个计数器计算特异度：内联样式(1,0,0,0)、ID选择器(0,1,0,0)、类与伪类(0,0,1,0)、标签与伪元素(0,0,0,1)。理解特异度算法是根治滥用`!important`暴力覆盖样式的唯一科学解药。

    分析一段选择器：`div#sidebar ul.nav li a:hover`特异度为(0,1,2,3)，比单纯的`#sidebar a:hover`(0,1,0,2)更具优先权，演示了精准控制样式权重的层叠算力。

  2. 2. 盒模型与IE5.5怪异盒模型的千古公案

    W3C标准盒模型的width仅包含content内容区（加padding和border会撑大物理尺寸），而微软旧版IE在怪异模式下width包含了padding和border。理解Doctype声明激活标准模式，奠定了跨浏览器像素级还原的基石。

    为一个固定宽度200px的侧边栏添加各20px的内边距，标准模式下总占据宽度瞬间膨胀至240px导致页面右侧栏被挤落掉行，演示了盒模型计算失误引发的雪崩效应。

  3. 3. 外边距折叠（Margin Collapsing）的物理规律

    在垂直方向上，相邻的两个块级元素的外边距不会简单相加，而是发生‘折叠（合并）’，最终间距取两者中的较大值；甚至当父元素无边框和内边距时，子元素的marginTop会神奇穿透父元素顶端折叠出去。

    上方段落设置marginBottom为30px，下方段落设置marginTop为20px，两段落之间的实际渲染物理间距是30px而非50px，揭示垂直排版中避免空白溢出的自然排版智慧。

  4. 4. 浮动闭合（Clearfix）与格式化上下文

    当子元素全部设置float浮动后，脱离正常文档流会导致父元素高度塌陷为0。通过经典的`.clearfix:after { content: ''; display: block; clear: both; }`微格式，或者触发BFC（块级格式化上下文），能够优雅包裹浮动子元素。

    解构一个图文混排新闻卡片：两列浮动文字导致外层带背景色的边框完全压扁成一条细线，在父容器注入闭合伪元素后，背景色瞬间平滑撑开包裹两列内容。

  5. 5. CSS Sprites（雪碧图）的HTTP性能革命

    在早期HTTP/1.1连接限制下，网页加载几十个小图标会产生几十次昂贵的TCP三次握手请求。将所有小图标拼合在一张大图（Sprite）中，利用`background-position`坐标偏移按需截取展示，大幅削减页面加载耗时。

    将导航栏常态、鼠标悬停（Hover）与点击激活（Active）三态按钮图标垂直拼接在一张PNG图片上，不仅消除了鼠标划过时图片临时下载产生的短暂白块闪烁，更将HTTP请求数直接减少了三分之二。

全书结构

  1. 第1章 基础知识：语义化标记与层叠秩序

    建立现代Web标准基本范式，阐述Doctype模式切换、语义化HTML结构、选择器类型、特异度权重计算与层叠继承规则。

    以一份经典个人博客简历为例，展示如何将充斥着嵌套表格与font标签的混乱HTML重构成仅有十几个语义标签的纯净骨架。

  2. 第2章 盒模型与视觉格式化模型

    深度剖析标准盒模型与IE怪异盒模型，详解内边距、边框、外边距折叠机制，以及行内元素、块级元素与行内块元素的display转换。

    通过放大至像素级的剖面图，演示外边距折叠在段落列表、标题间隙处的动态计算逻辑与触发避免策略。

  3. 第3章 背景图像与文字排印艺术

    掌握高阶背景定位与平铺（滑动门技术Sliding Doors），深入探讨Web安全字体、字号阶梯、行高（Line-Height）微力学与两端对齐排版。

    详细演示滑动门圆角按钮技术：利用两张微小背景图的相互滑动拉伸，实现能够包裹任意长度文字的完美自适应圆角按钮。

  4. 第4章 页面布局：浮动、定位与弹性多栏

    系统讲解相对定位、绝对定位、固定定位与浮动布局，详述圣杯布局、双飞翼布局与闭合浮动的各大工程方案。

    手把手构建自适应流式三栏布局（左右两栏固定宽度、中间内容栏自适应屏幕伸缩），解析负边距（Negative Margin）的精妙应用。

  5. 第5章 表单美化与无障碍界面增强

    攻克Web开发中最繁琐的表单输入框、单选复选框美化，确保Label关联、Focus键盘焦点轮廓与屏幕阅读器无障碍可访问性兼备。

    展示如何用纯CSS隐藏原生丑陋的checkbox并用精美矢量图标与CSS伪类替代，同时保持Tab键完整焦点切换操作。

  6. 第6章 跨浏览器Bug排查与工程化维护

    总结全书，归纳IE6/7常见疑难杂症速查表（如双边距Bug、3像素Bug），阐释条件注释、CSS重置（Reset）与组件化样式架构思想。

    演示经典CSS Reset样式重置清单的编写，抹平不同浏览器对ul内边距、body外边距的预设差异，实现跨平台一致性渲染。
